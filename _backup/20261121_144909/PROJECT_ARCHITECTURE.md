# 專案架構文件 (PROJECT_ARCHITECTURE.md)

## 區塊一：專案概述
本專案「訂單、保卡與發票拼貼工作台」（`OrderCollageTool`）為專供實體專櫃業務與審核作業打造的本機桌面影像拼貼輔助工具。現已全面重構為**100% 純前端免安裝版本**，並全面升級為 **`2400 × 1700` px 超高解析度畫布**（橫向 A4 比例）與 **4.5x PDF 銳利渲染**。具備「保卡/發票進場自動偵測白紙去背景」、「櫃位印章日期 1.4x 放大與 localStorage 永久記憶」、「+12px 總金額切線精準切齊」與「預設三欄式黃金版面自動定位」四大核心優化。

## 區塊二：系統技術架構（100% 純前端綠色免安裝）
1. **純前端影像與文件運算引擎（HTML5 Canvas + Vanilla JS）**：
   - **4.5x PDF 超高解析度轉檔與 +12px 精準裁切**：透過 Mozilla `pdf.js` CDN，於瀏覽器端以 4.5x 渲染比例產生極致清晰的訂單點陣圖。透過文字 Y 軸座標分析，精準切齊「總金額(含稅)」橫線正下方（安全邊界 +12px），徹底避免切到施工確認文字。
   - **自動白紙輪廓偵測與單應性透視去背景**：純 JavaScript 像素亮度（$L > 125$）與色彩飽和度（$\Delta < 55$）分析，在照片進場時自動尋找白紙主區域四角頂點並執行透視拉正裁切；選取後支援「調整四角裁切」微調與「還原原始未裁切全圖」。
   - **四點透視變形校正（Homography 逆向雙線性插值）**：純 JavaScript 實作 3×3 Projective 映射矩陣與雙線性插值（Bilinear Interpolation）演算法，在瀏覽器端一鍵將斜拍紙張四角拉直為標準矩形並去除雜亂背景。
   - **文件掃描美化（純 JS 背景光度除陰影演算法）**：純 JavaScript 像素遍歷與局部背景估算，手動開啟即可即時去除桌面陰影並增白底紙，支援去陰影強度、亮度、對比度滑桿微調。
   - **印章 Base64 內嵌與 localStorage 永久記憶**：專櫃印章使用 Base64 Data URL 內嵌，徹底杜絕跨域安全限制；日期字體放大約 1.4 倍（175px），支援字體大小與垂直 Y 軸微調，自動記憶於瀏覽器 `localStorage`；預設蓋章尺寸為 400px，適配保卡經銷商章欄位。

2. **前端操作工作台（單頁式 HTML5 / Canvas）**：
   - **畫布規格**：`2400 × 1700` px（橫向 A4 規格），Canvas 設定 `imageSmoothingQuality = 'high'`，確保細小文字無損銳利。
   - **預設三欄式黃金版面**：
     - **訂購單（PDF）**：進場置於左上角，寬度佔畫布約 63%。
     - **保卡 / 橫向單據（寬 >= 高）**：進場置於左下角，寬度佔畫布約 58% 對齊訂購單。
     - **發票 / 直式明細（高 > 寬）**：進場置於右側直立區，高度佔滿畫布約 88%。
     - **印章**：預設尺寸 400px，置於保卡蓋章欄位。
   - **圖層管理機制**：所有元件均為獨立圖層，支援拖曳移動、4 角落等比例拉伸、頂部 360° 自由旋轉與層級調整。

3. **啟動腳本**：
   - `啟動拼貼工具.bat`：免檢查 Python、免安裝任何套件，雙擊後直接呼叫系統預設瀏覽器開啟根目錄之 `index.html`。

## 區塊四：核心功能詳細規格
1. **白紙輪廓偵測與自動去背景裁邊**：
   - 縮圖分析像素亮度與色彩飽和度，偵測白紙有效區域並萃取 4 個極值頂點。
   - 經面積檢驗確認為有效邊界後，自動執行 Homography 逆向雙線性插值透視拉正裁切。
   - 提供「調整四角裁切」微調與「還原原始未裁切全圖」還原按鈕。

2. **4.5x 訂購單超高解析度與 +12px 切線修正**：
   - Mozilla `pdf.js` 解析度拉升至 4.5x，搭配 high-quality 雙線性平滑。
   - 文字 Y 軸下緣安全邊界由 +35px 縮減至 `+12px`，精準切齊「總金額(含稅)」橫線正下方，不留施工確認文字。

3. **櫃位印章自訂與 localStorage 永久記憶**：
   - 內嵌 `static/stamp_data.js` 之 `STAMP_CLEAN_BASE64`，免疫跨域限制。
   - 日期文字放大 1.4 倍（預設 175px），提供字體大小與 Y 軸垂直偏移微調滑桿。
   - 微調即時反映於預覽圖，並自動同步儲存至 `localStorage`，開箱即記住喜好設定。

4. **預設三欄式黃金版面**：
   - 訂購單置於左上角（寬 63%）。
   - 橫向保卡置於左下角（寬 58% 對齊訂單）。
   - 直向發票置於右側直立區（高 88%）。
   - 各物件進場後仍為獨立可操作圖層。

5. **高解析度 PNG 匯出**：
   - 輸出規格升級為標準橫向 A4 `2400 × 1700` px，隱藏輔助線框與控制點，一鍵無損匯出。
