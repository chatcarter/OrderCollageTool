# 專案架構文件 (PROJECT_ARCHITECTURE.md)

## 區塊一：專案概述
本專案「訂單、保卡與發票拼貼工作台」（`OrderCollageTool`）為專供實體專櫃業務與審核作業打造的本機桌面影像拼貼輔助工具。現已全面重構為**100% 純前端免安裝版本**，完全脫離 Python 後端與本機伺服器依賴，任何受限環境下只要有現代化瀏覽器（Chrome / Edge）即可雙擊秒開使用。一站式整合客戶訂購單（PDF）、保證書/保卡照片、發票照片、櫃位專屬印章（含動態民國年日期合成）以及審核備註文字，並無損匯出為高解析度（1600 × 1130 px，橫向 A4 規格）PNG 影像。

---

## 區塊二：系統技術架構（100% 純前端綠色免安裝）
1. **純前端影像與文件運算引擎（HTML5 Canvas + Vanilla JS）**：
   - **PDF 高解析度轉檔與智慧識別**：透過 Mozilla `pdf.js` CDN，在瀏覽器端直接解析 PDF 二進位資料流並以 2.5x 縮放渲染出超高解析 Canvas。透過 `page.getTextContent()` 解析內文字元座標，精準定位「實收訂金金額 / 尚餘尾款 / 總金額(含稅)」所在列座標，自動切除下方「施工確認項目」與相關條款，並支援即時滑桿微調。
   - **四點透視變形校正（Homography 逆向雙線性插值）**：純 JavaScript 實作 3×3 Projective 映射矩陣與雙線性插值（Bilinear Interpolation）演算法，在瀏覽器端一鍵將斜拍紙張四角拉直為標準矩形並去除雜亂背景。
   - **文件掃描美化（純 JS 背景光度除陰影演算法）**：純 JavaScript 像素遍歷與局部背景估算，手動開啟即可即時去除桌面陰影並增白底紙，支援去陰影強度、亮度、對比度滑桿微調。
   - **印章 Base64 內嵌與動態日期合成**：已去背印章全面轉為 Base64 Data URL 內嵌於 `static/stamp_data.js` 中，徹底避免本機 `file:///` 協議下的 `Tainted Canvas` 安全性限制，確保日期精確合成與 Canvas 匯出永不報錯。

2. **前端操作工作台（單頁式 HTML5 / Canvas）**：
   - **版面切割**：左側 72% 純白畫布工作區（1600 × 1130 px 橫向 A4 比例，支援滾輪平滑縮放與拖曳平移）；右側 28% 控制面板（已匯入圖層清單、動態專屬控制面板、印章日期產生器、審核備註、高解析度無損匯出）。
   - **圖層管理機制**：所有進場元件（PDF 訂單、照片、印章、文字）皆為獨立物件（包含座標、縮放比例、旋轉弧度、層級 zIndex），支援滑鼠拖曳移動、4 角落等比例拉伸控制柄、頂部 360° 自由旋轉柄、微調鍵盤快捷鍵。

3. **啟動腳本**：
   - `啟動拼貼工具.bat`：免檢查 Python、免安裝任何套件，雙擊後直接呼叫系統預設瀏覽器開啟根目錄之 `index.html`。

## 區塊四：核心功能詳細規格
1. **櫃位印章提取與純前端防 CORS 機制**：
   - 提取自 `本櫃印章.docx` 之專櫃印章，去除白色背景與雜訊，色彩標準化為 `#003FBC` 專櫃藍。
   - 內嵌為 `static/stamp_data.js` 之 `STAMP_CLEAN_BASE64`，無論以本地 `file:///` 或網頁伺服器開啟皆 100% 免疫瀏覽器跨域限制。
   - 中心留白方框區域精準錨定：X 範圍 520~1365 px，Y 範圍 528~910 px，中心點 (942, 719)。

2. **純前端 PDF 智慧自動裁切（訂購單模式）**：
   - 使用 Mozilla `pdf.js` 解析內文文字座標，精準定位「實收訂金金額 / 尚餘尾款 / 總金額(含稅)」行底部座標加上 35px 安全留邊。
   - 自動切除下方「施工確認項目」與條款，並可透過右側面板滑桿手動微調裁切百分比（20%~100%）。

3. **保卡與發票照片（100% 原圖進場）**：
   - 拖曳或匯入圖片時完全維持原始色彩、無失真進場。
   - **四點透視拉正**：開啟校正模式後，使用者可拖曳四角圓點對齊紙張頂點，透過純 JS 單應性矩陣雙線性插值演算法將斜拍文件拉平為矩形並裁切背景。
   - **文件掃描美化**：預設關閉。手動開啟時提供「去陰影強度」、「亮度微調」、「對比微調」三項滑桿，即時濾除桌面陰影並增白底紙。

4. **動態民國年印章合成與備註文字**：
   - 印章日期預設帶入當天系統民國年（如 `115.11.21`），並以相同藍色 `#003FBC` 標楷體字型居中合成於印章方框。
   - 審核備註支援多行輸入、粗體、三色切換（黑 `#000000` / 紅 `#D32F2F` / 藍 `#003FBC`），拉動四個角落即可等比例縮放字體。

5. **高解析度 PNG 匯出**：
   - 輸出標準規格 `1600 x 1130` px，隱藏所有輔助框線與控制柄，繪製白色底板後逐層無損合成並觸發瀏覽器下載。
