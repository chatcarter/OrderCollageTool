# 專案架構文件 (PROJECT_ARCHITECTURE.md)

## 區塊一：專案概述
本專案「訂單、保卡與發票拼貼工作台」（`OrderCollageTool`）為專供實體專櫃業務與審核作業打造的本機桌面影像拼貼輔助工具。主要功能在於一站式整合客戶訂購單（PDF）、保證書/保卡照片、發票照片、櫃位專屬印章（含動態民國年日期合成）以及審核備註文字，並無損匯出為高解析度（1600 × 1130 px，橫向 A4 規格）PNG 影像，大幅提升審核拼貼之效率與品質。

---

## 區塊二：系統技術架構
1. **後端影像引擎（Python）**：
   - **Web 框架**：Flask 提供本機 RESTful API 與靜態檔案伺服。
   - **PDF 高解析度轉檔與智慧識別**：使用 PyMuPDF (`fitz`) 將 PDF 訂單以 2.5x（高解析度）轉成點陣圖，並透過內文座標萃取演算法自動搜尋「實收訂金金額 / 尚餘尾款 / 總金額(含稅)」所在列座標，精準裁除下方施工項目與條款。
   - **電腦視覺與影像增強**：OpenCV (`cv2`) 負責斜拍照片的「四點透視變形校正（拉直去背景）」以及「文件掃描美化（光照背景估算除陰影、亮度對比增強）」。
   - **影像與文字精確合成**：Pillow (`PIL`) 處理專櫃印章 Alpha 通道去背、`#003FBC` 藍色印泥色彩標準化，以及民國年動態日期之中心對齊繪製。

2. **前端操作工作台（單頁式 HTML5 / Canvas）**：
   - **版面切割**：左側 72% 純白畫布工作區（1600 × 1130 px 橫向 A4 比例，支援滾輪平滑縮放與拖曳平移）；右側 28% 控制面板（已匯入圖層清單、動態專屬控制面板、印章日期產生器、審核備註、高解析度無損匯出）。
   - **圖層管理機制**：所有進場元件（PDF 訂單、照片、印章、文字）皆為獨立物件（包含座標、縮放比例、旋轉弧度、層級 zIndex），支援滑鼠拖曳移動、4 角落等比例拉伸控制柄、頂部 360° 自由旋轉柄、微調鍵盤快捷鍵。
   - **客戶端雙軌容錯（Client Fallback）**：前端內建純 Canvas/JavaScript 影像濾鏡與透視演算法，在後端 Python 環境啟動前或單純開啟 HTML 時仍能正常顯示與操作。

3. **啟動腳本**：
   - `啟動拼貼工具.bat`：自動檢測本機 Python 環境、安裝 `requirements.txt`、觸發印章去背初始化、開啟伺服器並呼叫預設瀏覽器導向 `http://127.0.0.1:5000`。

## 區塊四：核心功能詳細規格
1. **櫃位印章提取與完美去背（`assets/stamp_clean.png`）**：
   - 提取自 `本櫃印章.docx` 之 `word/media/image1.png`。
   - 透過顏色明度估算公式 $0.35R + 0.55G + 0.10B$ 生成 Alpha 通道遮罩，徹底去除白色底紙與陰影雜訊。
   - 所有實體印泥線條色彩皆正規化為 `#003FBC`（專櫃標準藍），邊緣維持平滑平坦化反鋸齒。
   - 中心留白方框區域精準錨定：X 範圍 520~1365 px，Y 範圍 528~910 px，中心點 (942, 719)。

2. **PDF 智慧自動裁切（訂購單模式）**：
   - 解析 PDF 內文文字座標，精準定位「實收訂金金額 / 尚餘尾款 / 總金額(含稅)」行底部座標加上 15pt 安全留邊。
   - 自動切除下方「施工確認項目」與客戶須知條款，並可透過右側面板滑桿手動微調裁切百分比（20%~100%）。

3. **保卡與發票照片（100% 原圖進場）**：
   - 拖曳或匯入圖片時完全維持原始色彩、無失真進場。
   - **四點透視拉正**：開啟校正模式後，使用者可拖曳四角圓點對齊紙張頂點，調用 OpenCV `getPerspectiveTransform` 與 `warpPerspective` 將斜拍文件拉平為矩形並裁切背景。
   - **文件掃描美化**：預設關閉。手動開啟時提供「去陰影強度」、「亮度微調」、「對比微調」三項滑桿，即時濾除桌面陰影並增白底紙。

4. **動態民國年印章合成與備註文字**：
   - 印章日期預設帶入當天系統民國年（如 `115.11.21`），並以相同藍色 `#003FBC` 標楷體字型居中合成於印章方框。
   - 審核備註支援多行輸入、粗體、三色切換（黑 `#000000` / 紅 `#D32F2F` / 藍 `#003FBC`），拉動四個角落即可等比例縮放字體。

5. **高解析度 PNG 匯出**：
   - 輸出標準規格 `1600 x 1130` px，隱藏所有輔助框線與控制柄，繪製白色底板後逐層無損合成並觸發瀏覽器下載。
